## Lite om mig
Jag är en frontendutvecklare under utbildning med en kandidatexamen i grafisk design, en kombination som gör att jag förstår både koden och känslan bakom ett gränssnitt. Jag innehar kunskaper inom HTML, CSS, Sass, JavaScript, TypeScript och Figma, och kommer även vid LIA-start ha kurser i React och API-integration bakom mig. Nu söker jag en praktikplats där jag kan växa som frontendutvecklare i ett engagerat team. 

## Kompetenser

Gedigna kunskaper inom HTML, CSS, Sass, JavaScript och TypeScript, samt grafisk formgivning och UX. Till LIA tar jag även med färska kunskaper i React och API-integrationer. Min designbakgrund gör att jag talar samma språk som designern och kan översätta komplexa skisser till pixelperfekt, responsiv kod.
